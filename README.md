# Data Science Portfolio

A collection of projects in applied statistics, Bayesian methods, data mining,
deep learning, machine learning, predictive analytics, recommenders,
responsible data science, time series, and visualization.

Most case studies include a Markdown explanation and a notebook, R script, or
report. Dependencies vary by project; see the individual project notes before
running a notebook or script. Results in synthetic-data exercises are
illustrative and should not be interpreted as clinical, financial, or
operational advice.

## Reproducibility

- Check the project-specific README for its data source and package requirements.
- Use the supplied synthetic exercise when you need a dependency-light example.
- Keep generated files and local environment settings out of version control.
- Report validation metrics and limitations; do not imply a model is suitable for
  deployment based only on a demonstration.
