# Difference-in-differences impact evaluation

This base-R workflow creates a seeded panel with a treated and a comparison
group across pre- and post-intervention periods. It estimates the difference
between group-level changes and reports a percentile confidence interval from
a cluster bootstrap that resamples units, not individual rows. The example
data are illustrative and generated by the script.

Run from the repository root:

```bash
Rscript "Exercises/Impact Evaluation/difference_in_differences.R"
```

The reported pre-intervention slope gap is a diagnostic, not proof of parallel
trends. A causal interpretation also requires a defensible comparison group,
no important concurrent intervention, stable measurement, and no material
spillovers. The exercise is educational and does not report a real program
effect.
